# Mind Your Language

A single-page tool for speech pathologists: pick a discourse genre for a school-age client, rate a language sample, and get goals, a session plan, a parent sheet and report references.

- `index.html` is the whole app. Open it in a browser.
- Opened outside Claude, client files save in that browser only, and the Claude-powered checks (persuasive sample scoring, Story page "Check the story") are unavailable.
- `pn/` holds the photos for the personal narrative photo prompts (Westerveld & Gillon language sampling protocol, Australian set).
- Use client initials, not names.

Conversation rubrics are adapted from CPPEV, © 2021 Anna Vagin, PhD. Sources for the clinical content are listed on the app's References step.
